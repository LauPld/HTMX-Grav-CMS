# HTMX-Grav-CMS
A practical example project demonstrating how to apply [HTMX](https://github.com/bigskysoftware/htmx) patterns and progressive enhancement techniques within [Grav CMS](https://github.com/getgrav/grav), combining server-side rendering, Twig templates, PHP, and lightweight client-side interactions

## Contains :

- [x] `quark2child`, a custom child theme that adds the embedding HTMX function for modular pages via the `quark2child.php` file.
- [x] `twig`templates that hold the logic
- [x] Modular pages
- [x] `HTMX` library

### What it doesn't have

- [ ] Grav core
- [ ] `Quark2` theme
- [ ] `Plugins`, `accounts` folders

  Once you have those, juste add the `quark2child` theme, replace `config` and `pages` directories in your `user` directory.
